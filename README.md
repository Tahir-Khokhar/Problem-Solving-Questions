## Usage

Each file is self-contained and includes a demonstration with sample input and expected output.

Run any file directly with Python:

```bash
python 01_Problem.py
```

## Topics Covered

- **Strings**: reversing words, palindromes, unique characters
- **Lists**: duplicates, sorting, pairs, flattening, chunking, intersection
- **Dictionaries**: merging, filtering, grouping, inversion
- **Algorithms**: prime check, factorial, Fibonacci, GCD, leap year
- **File I/O**: reading, writing, CSV, logging
- **Regex & Validation**: emails, IP addresses
